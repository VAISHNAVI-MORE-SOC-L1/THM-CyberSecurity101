# 📜 Overview

The **Cyber Security 101** pathway by TryHackMe is a beginner-friendly learning path designed to build a strong cybersecurity foundation through practical exercises and hands-on labs.

This repository serves as my personal technical notebook, documenting everything I learned while completing the path.

Inside this repository you'll find:
